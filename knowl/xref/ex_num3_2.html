Example 1.5.12. Using the Midpoint Rule.

Use the Midpoint Rule with \(n=5\) to approximate \(\ds \int_0^1e^{-x^2}\, dx\text{.}\)
🔗
Solution.
We cannot use the table in Figure 1.5.10 that we used for the Trapezoidal, Right and Left Hand Rules when using the Midpoint Rule. The Trapezoidal rule averages the outputs of the function to obtain a more accurate estimate of the definite integral. The Midpoint Rule averages the inputs of each subinterval to create a rectangle with height \(f\left(\frac{x_{i-1}+x_{i}}{2}\right)\text{.}\) Generally \(f\left(\frac{x_{i-1}+x_{i}}{2}\right)\neq \frac{f(x_{i-1})+f(x_{i})}{2}\text{.}\)
🔗
So we will create a new table of values as shown in Figure 1.5.13. We have \(\dx=(1-0)/5=0.2\text{.}\) The midpoint of the first subinteval is at \(0+0.2(1/2)=0.1\) and each successive midpoint is \(0.2\) from the last.
🔗
So we have
\begin{align*} \int_0^1 e^{-x^2}\, dx \amp \approx 0.2(0.99+0.9139+0.7788+0.6126+0.4449)\\ \amp \approx 0.7480 \end{align*}
🔗
We approximate \(\ds \int_0^1 e^{-x^2}\, dx \approx 0.7480\text{.}\)
